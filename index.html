关于项目

系统维护大师 —— 让系统维护变得简单

本工具使用 Python + Tkinter 开发，通过 PyInstaller 打包为独立可执行文件， 无需安装任何依赖即可运行。集成硬件监控、垃圾清理、病毒修复、网络检测等模块， 致力于为用户提供一站式的 Windows 系统维护体验。
